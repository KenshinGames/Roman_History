# Roman_History

古代ローマ史

## 一日一ローマ（試作版）

古代ローマ史を、1日3問のクイズと、版図が動く地図つきの年表で覚える学習アプリの試作です。

公開先：https://kenshingames.github.io/Roman_History/

`main` ブランチに push すると、GitHub Pages に数分で反映されます。

### 画面

- **今日の三問**：日付ごとに決まる3問。「どちらが先？」「その頃、世界では」「古い順に並べる」の3種類。答えるたびに、絵と場所の地図つきの解説が出ます。終わると練習問題を何度でも解けます。
- **モザイク**：解説を1件読むごとに石が1枚はまり、49枚そろうと1枚の絵になります。
- **地図と年表**：上に固定した地図が、年表を送るのに合わせて版図と場所を切り替えます。出来事を開くと、絵、説明、いまイタリアで見られる場所、ローマ建国紀元での年が出ます。

連続日数と読んだ解説の数は、その端末のブラウザにだけ保存されます。

### 手元で開く

`index.html` をブラウザで開くだけで動きます。ビルドは不要です。

### ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | 画面の骨組み |
| `style.css` | 見た目と動き（明るい画面と暗い画面の両方） |
| `data.js` | 出来事データ（ローマ史49件、世界39件） |
| `images.js` | 絵と写真の一覧（説明、作者、ライセンス、出典） |
| `img/` | 絵と写真（横960px）。`img/t/` は一覧用の小さい版 |
| `map-data.js` | 地図の形と、時代ごとの版図（自動生成） |
| `app.js` | 出題、採点、地図、年表の表示 |

### 出来事を足す

`data.js` に1件書き足すと、問題と年表の両方に反映されます。

- `loc`（経度・緯度）と `at`（地名）を書くと、地図に印が付きます。
- 絵を付けるときは、`img/<id>.jpg`（横960px）と `img/t/<id>.jpg`（240×180px）を置き、`images.js` に1行足します。自分で撮った写真も同じ手順で使えます。

### 絵と写真について

27枚すべて Wikimedia Commons から取得し、縮小して使っています。

- 20枚はパブリックドメインまたは CC0 です。
- 7枚は CC BY-SA（作者の表示と同じ条件での共有が必要）です。作者・ライセンス・出典は `images.js` にあり、アプリの「絵と地図の出典」にも表示しています。
- 地図の陸地の形は Natural Earth（パブリックドメイン）です。

有料で配布する段階では、CC BY-SA の7枚を自分の写真に差し替えると扱いが単純になります。

### 内容の確認

`data.js` の年代と説明は、まだ資料と照合していません。人に広める前に全件を用語集や概説書で確認してください。

- `legend: true` は伝承上の年代、`approx: true` は「頃」の付く年代です。
- 特に確認したい項目：ガリア人のローマ占領の年、マリウスの軍制改革の評価、カニシカ王の年代、卑弥呼の遣使の年。
- 地図の版図は、時代ごとのおおよその範囲を手で引いたものです。細かい境界は正確ではありません。
