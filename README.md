# Roman_History

古代ローマ史

## 一日一ローマ（試作版）

古代ローマ史を、1日3問のクイズと年表で覚える学習アプリの試作です。
ローマの出来事と、同じ頃に世界で起きていた出来事を並べて見られます。

### 開き方

`index.html` をブラウザで開くだけで動きます。ビルドは不要です。
GitHub Pages で公開する場合は、このリポジトリのルートを公開元に指定します。

### 画面

- **今日の三問**：日付ごとに決まる3問。「どちらが先？」「その頃、世界では」「古い順に並べる」の3種類。終わると練習問題を何度でも解けます。
- **年表**：王政・共和政・元首政・専制君主政の4区分。出来事を開くと、説明、いまイタリアで見られる場所、ローマ建国紀元での年が出ます。

連続日数と読んだ解説の数は、その端末のブラウザにだけ保存されます。

### ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | 画面の骨組み |
| `style.css` | 見た目（明るい画面と暗い画面の両方） |
| `data.js` | 出来事データ（ローマ史49件、世界39件） |
| `app.js` | 出題、採点、年表の表示 |

出来事を足すときは `data.js` に1件書き足すだけで、問題と年表の両方に反映されます。

### 内容の確認

`data.js` の年代と説明は、まだ資料と照合していません。公開前に全件を用語集や概説書で確認してください。

- `legend: true` は伝承上の年代、`approx: true` は「頃」の付く年代です。
- 特に確認したい項目：ガリア人のローマ占領の年、マリウスの軍制改革の評価、カニシカ王の年代、卑弥呼の遣使の年。
